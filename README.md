# 🎵 Music Playlist Manager

> A Python-based playlist management system that demonstrates the practical implementation of a **Doubly Linked List**.

### ✨ Features

- Add songs to the playlist
- Display all songs
- Play the current song
- Move to the next song
- Move to the previous song
- Search for a song
- Delete a song
- Menu-driven interface

### 🧠 Data Structure

The project uses a **Doubly Linked List**.

Each song is represented as a node containing:

- **Song title**
- **Artist name**
- **Previous reference**
- **Next reference**

**Playlist structure:**

`NULL ← Song 1 ⇄ Song 2 ⇄ Song 3 → NULL`

This allows navigation in both forward and backward directions.

### ⚙️ Operations

| Operation | Description |
|---|---|
| Add | Adds a new song |
| Display | Shows all songs |
| Next | Moves to the next song |
| Previous | Moves to the previous song |
| Search | Finds a song by title |
| Delete | Removes a song |

### ⏱️ Complexity

| Operation | Complexity |
|---|---|
| Add Song | O(n) |
| Search Song | O(n) |
| Delete Song | O(n) |
| Display Playlist | O(n) |
| Next Song | O(1) |
| Previous Song | O(1) |

### ▶️ How to Run

1. Download or clone this repository.
2. Make sure Python is installed.
3. Open the project folder in VS Code or a terminal.
4. Run `python music_playlist.py`.
