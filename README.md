# 🎵 Music Playlist Manager

A beginner-friendly Music Playlist Manager built using **Python** and **Doubly Linked List**.

## 📌 Features

- Add a song
- Display playlist
- Play current song
- Play next song
- Play previous song
- Search for a song
- Delete a song
- Menu-driven interface

## 🧠 DSA Concept
This project uses a **Doubly Linked List**.
Each song is stored as a node containing:

- Song title
- Artist name
- Previous pointer
- Next pointer

```text
NULL ← Song 1 ⇄ Song 2 ⇄ Song 3 → NULL
